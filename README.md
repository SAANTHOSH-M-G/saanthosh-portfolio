# Saanthosh M G — Portfolio

Offline-first React portfolio inspired by the visual structure and motion language of the referenced portfolio tutorial.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Main stack

React + Vite + GSAP + ScrollTrigger + Lenis + Lucide React.

## Profile data

The portfolio reflects the education and experience details shown in the supplied LinkedIn screenshots, plus the supplied LinkedIn profile URL. The hero uses an original abstract security visual rather than a third-party person's photo.
